# Ayurveda Search Engine

A powerful Ayurveda herb and remedy search engine built with MeiliSearch.

## Features
- Fast full-text search across Ayurvedic herbs, remedies, and treatments
- MeiliSearch-powered backend for instant results
- Clean, responsive UI
- MCP Server integration
- Persistent memory and ranking scores

## Getting Started

Run `Start Ayurveda Explorer.bat` to launch the application.

## Project Structure
- `ayurveda_meili/` - Main search app (MeiliSearch + API)
- `Meili MCP Server/` - MCP server integration
- `Pipeline/` - Data pipeline scripts
- `Website/` - Frontend assets
- `Final data/` - Processed Ayurveda dataset
